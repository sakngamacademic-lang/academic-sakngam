## หลักการจับคู่ (`src/features/mapping/match.ts`, ไม่ใช้ AI)
1. **ระดับ 1 รหัสตรง** — รหัสที่โรงเรียนระบุ (หน่วย/คำอธิบาย/ผลการเรียนรู้) + ตรวจระดับชั้น + ตรวจข้อความ
2. **ระดับ 2 หลักฐานจากเนื้อหา** — ข้อความสอดคล้องสูง (ตัดคำไทย, น้ำหนักคำแบบ IDF, วลีคู่คำ)
3. **ระดับ 3 ระบบเสนอ** — สอดคล้องพอประมาณ ไม่มีรหัส
- ความคล้ายของข้อความอย่างเดียว **ไม่ตัดสินว่าครอบคลุม** · “ครอบคลุม” = ฝ่ายวิชาการยืนยันแล้วเท่านั้น
- ผลความครอบคลุมแยกจากสถานะการยืนยัน (ยังไม่ยืนยัน/ยืนยันแล้ว/ปฏิเสธ)
- % และกราฟวงแหวนแสดงเฉพาะฐานรับรองแล้ว **และ** `is_complete = true`

## ข้อมูลจริงพอสำหรับระดับใด
- ตอนนี้ใช้ได้: **ระดับ 2–3 จากคำอธิบายรายวิชา** เทียบผลอ่าน SRC-02 (ยังไม่รับรอง) — แสดงเป็น “ผลเปรียบเทียบเบื้องต้น — ยังไม่รับรอง”
- ระดับ 1 ระดับหน่วย: ยังไม่ได้ เพราะยังไม่มีหน่วยการเรียนรู้และไม่มีรหัสตัวชี้วัดที่ระบุ
- สังคมศึกษา: ฐานอ้างอิงมีเฉพาะ ส 5.1/5.2 (ภูมิศาสตร์) — ส 1–4 ยังไม่อยู่ในฐาน

## ขั้นตอนให้ยืนยัน Mapping ได้บน Staging (ทำผ่านหน้าเว็บโดยผู้ดูแลหลักสูตร — ไม่ต้องรัน migration)
1. เครื่องมือฝ่ายวิชาการ → อ่านเอกสารอัตโนมัติ → ตรวจรับรองรายการ SRC-02 แล้ว “บันทึกเป็นกรอบแกนกลาง”
2. ประกาศใช้หลักสูตร (ฉบับทางการ) → ผูกหลักสูตร 2569 กับกรอบแกนกลางที่บันทึก
3. ตั้ง `learning_areas.national_area_code` (เช่น สังคมฯ = ส) — trigger เดิมตรวจกลุ่มสาระก่อนบันทึกการจับคู่
4. ถ้ายืนยันว่าฐานครบ (`framework_version_confirm`) จึงจะแสดง %
