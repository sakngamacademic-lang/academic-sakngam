## สถานะ (คำนวณใน `presentation/status.ts` · ทดสอบ `scripts/presentation-status.test.ts`)
- แกนการยืนยันของโรงเรียน: ยืนยันแล้ว / ไฟล์เปลี่ยนหลังยืนยัน (sha256 ไม่ตรง) / ยังไม่บันทึก
- แกนการตรวจความสอดคล้อง: **ผ่าน** = มีกฎที่ยืนยันกับต้นฉบับ + ผลตรวจผ่านทุกข้อ + ไม่มีข้อสงสัยค้าง · **พบประเด็นที่ต้องแก้ไข** = มี CF ที่ยืนยันแล้วรอตัดสิน หรือกฎไม่ผ่าน · อื่น ๆ = อยู่ระหว่างการตรวจทบทวน
- “โรงเรียนยืนยัน” ไม่ถูกนำไปคำนวณแกนที่สองในทุกกรณี
