## 5. งานถัดไป: สกัดข้อมูลจาก SRC-01 (รอไฟล์)

ผู้ใช้สั่งให้เริ่มสกัดจาก SRC-01 เพียงไฟล์เดียว (ยังไม่ใช้ Excel / ZIP) — ขั้นตอนเมื่อไฟล์อยู่ใน environment:

1. sha256 + จำนวนหน้า เทียบกับผลตรวจ (547 หน้า) ก่อนเริ่ม
2. สารบัญ → แผนที่ส่วน (ประกาศ, โครงสร้างเวลาเรียน, โครงสร้างรายชั้น, คำอธิบายรายวิชา, มาตรฐาน/ตัวชี้วัด, กิจกรรมพัฒนาผู้เรียน) พร้อมช่วงหน้า PDF
3. สกัดข้อความทีละหน้า → แถว staging ในไฟล์ผลลัพธ์ (ยังไม่เข้า DB): รายวิชา (รหัส/ชื่อ/ประเภท/หน่วยกิต/ชั่วโมง/ภาค/ชั้น/แผน), กิจกรรม, มาตรฐาน/ตัวชี้วัด (ระหว่างทาง/ปลายทาง), คำอธิบายรายวิชา/ผลการเรียนรู้ — ทุกแถวมี `pdf:` page
4. ข้อความไทยที่สกัดผิดเพี้ยน / ตารางที่อ่านโครงสร้างไม่ได้ → `needs_review` พร้อมเหตุผล ไม่เติมค่า
5. รายงาน: จำนวนที่สกัดได้ต่อประเภท · จำนวน needs_review · ส่วนที่ขาด
