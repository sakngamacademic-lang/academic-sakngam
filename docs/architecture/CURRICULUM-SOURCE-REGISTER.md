## 2. ระดับความน่าเชื่อถือ (ใช้กับทุกเอกสาร)

| ระดับ | ความหมาย | ใช้ยืนยันข้อมูลหลักได้หรือไม่ |
|---|---|---|
| **A** authoritative | ประกาศ/เล่มหลักสูตรที่ผู้บริหารลงนามอนุมัติ | ได้ — เป็นหลักฐานสุดท้ายเมื่อขัดแย้ง |
| **B** official_supporting | เอกสารทางการประกอบ (หลักสูตรกลุ่มสาระ, ระเบียบวัดผล) | ได้ หากไม่ขัดกับ A |
| **C** working_draft | ไฟล์ทำงาน (Excel) | ใช้เป็นข้อมูลนำเข้าได้ แต่ทุกแถวต้องตรวจเทียบ A/B ก่อน commit |
| **D** unknown | ไม่ทราบที่มา / ไม่มีวันที่ | ไม่ใช้ยืนยัน |

กติกา
1. **ไฟล์ชื่อใหม่กว่าไม่ได้ถูกต้องกว่าเสมอ** — ลำดับความน่าเชื่อถือใช้ระดับ A → B → C ไม่ใช่ชื่อไฟล์หรือวันที่แก้ไข
2. การเริ่มใช้หลักสูตร 2569 กับ ม.1 และ ม.4 ต้องอ้าง **เลขหน้าในประกาศของ SRC-01** (บันทึกใน `curriculum_versions.announcement_*`)
3. ทุกค่าที่นำเข้าต้องมีที่มา: ไฟล์ + Sheet/Cell หรือ PDF หน้า
4. ข้อขัดแย้งบันทึกในตาราง `source_conflicts` พร้อมผู้ตัดสินและเหตุผล — ไม่เขียนทับเงียบ ๆ

## 4. ขั้นตอนเมื่อได้รับไฟล์ (C1.1 — รออนุมัติ)

1. ผู้ใช้ส่งไฟล์เข้า session (upload) หรือระบุตำแหน่ง — **ไม่ commit ไฟล์ต้นฉบับเข้า Git** จนกว่าจะยืนยันว่าไม่มีข้อมูลส่วนบุคคล
2. คำนวณ SHA-256 ทุกไฟล์ (รวมไฟล์ย่อยใน ZIP) → บันทึกใน register นี้
3. เติมคอลัมน์ "รอตรวจ" จากเนื้อเอกสารจริง พร้อมเลขหน้า/Sheet/Cell
4. บันทึกข้อขัดแย้งที่พบ แล้วเสนอผู้มีอำนาจตัดสิน (academic_head)
