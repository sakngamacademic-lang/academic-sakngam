1. **ไฟล์ชื่อใหม่กว่าไม่ได้ถูกต้องกว่าเสมอ** — ตัดสินด้วยระดับ A → B → C (ตัวอย่างจริง: CF-03 ชื่อไฟล์ "ปรับปรุง 69" แต่เนื้อหาระบุ 2561)
2. การเริ่มใช้หลักสูตร 2569 กับ ม.1 และ ม.4 อ้าง **SRC-01 PDF หน้า 4** (เล่มหน้า 3)
3. ทุกค่าต้องมีที่มาตามรูปแบบ locator ใน Data Dictionary §0 (แยกหน้า PDF กับหน้าเล่ม)
4. ข้อขัดแย้งบันทึกใน `source_conflicts` — ไม่เขียนทับเงียบ ๆ
