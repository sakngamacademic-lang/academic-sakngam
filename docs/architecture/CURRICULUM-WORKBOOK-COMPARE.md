# เทียบไฟล์โครงสร้างหลักสูตร (Excel) กับทะเบียนรายวิชา — อ่านอย่างเดียว

หน้า `/office/curriculum/workbook-compare` (เมนู เครื่องมือฝ่ายวิชาการ → ตรวจหลักสูตรและข้อมูล)

- **ไฟล์อ่านในเบราว์เซอร์เท่านั้น** (`src/lib/xlsx-read.ts` ไม่มี dependency ใช้ `DecompressionStream`) ไม่อัปโหลด ไม่บันทึก แสดง SHA-256 ของไฟล์ไว้อ้างอิง
- ตัวอ่าน `structure-workbook.ts` อ่านบล็อกละ 4 คอลัมน์ (ตัวกำกับ / รหัส / ชื่อ / `หน่วยกิต(ชั่วโมง)`) ต่อภาคเรียน
  - แถว 1 = ชื่อโครงสร้าง/แผน, แถว 2 = ชั้น/ห้อง, แถว 3 = ภาคเรียน
  - เก็บค่าดิบคู่กับค่าที่แยกได้ และอ้างอิง `ชีต!เซลล์` ทุกรายการ
  - รหัสที่มีเลขไทยจะแปลงเพื่อการเทียบเท่านั้น ส่วนค่าดิบยังเก็บไว้
- ตัวเทียบ `structure-compare.ts` จับคู่แผนในระบบโดยดูสัดส่วนรหัสวิชาที่ตรงกันในชั้นและภาคเดียวกัน (ไม่เดาจากชื่อ)
  - ถ้าคะแนนต่ำกว่า 50% หรือสองแผนแรกคะแนนห่างกันไม่ถึง 5% → แสดง “ต้องให้ฝ่ายวิชาการเลือก”
  - ประเภทความต่าง:
    - มีในไฟล์แต่ไม่มีในระบบ
    - มีในระบบแต่ไม่มีในไฟล์
    - ชื่อวิชาต่างกัน
    - ชื่อต่างเฉพาะรูปแบบ
    - หน่วยกิตต่างกัน
    - ชั่วโมงต่างกัน
    - ยอดรวมต่างกัน
  - ตรวจภายในไฟล์ด้วย:
    - หน่วยกิตไม่สัมพันธ์กับชั่วโมง (40 ชม./นก.)
    - ยอดที่ระบุไม่เท่ากับผลรวม
    - รหัสมีเลขไทยปน
- **ห้องเรียน**: เสนอผูกห้องเฉพาะเมื่อไฟล์ระบุ “ชั้นมัธยมศึกษาปีที่ X/Y” และระบบมีห้องนั้นอยู่จริง
  - ม.4–ม.6 ในไฟล์ไม่ระบุเลขห้อง จึงไม่เสนอ
  - ข้อเสนอยังไม่ถูกบันทึก: การเขียน `classroom_programs` ต้องได้รับอนุมัติแยกต่างหาก
- ดาวน์โหลดรายงานเป็น CSV ได้ (UTF-8 BOM) โดยระบบไม่แก้ทะเบียน ไม่เปลี่ยนสถานะ และไม่ตัดสินแทนฝ่ายวิชาการ
