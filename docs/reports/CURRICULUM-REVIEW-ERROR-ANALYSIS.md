## 2. ความเสี่ยงที่พบ: ข้อมูลพื้นฐานของโรงเรียนบน Hosted ยังว่าง

Hosted มี `learning_areas = 0` และ `grade_levels = 0` (ข้อมูลเหล่านี้มาจาก seed ของ Local ซึ่งไม่ถูกโอน/ไม่ได้ seed บน Hosted)
ถ้าบันทึกชุดแผน/รายวิชาแล้วตรวจซ้ำตอนนี้ ทุกแถวจะติด V13 (กลุ่มสาระ) และตรวจระดับชั้นไม่ได้
→ ต้องสร้างกลุ่มสาระ 8 กลุ่ม (TH MA SC SO PE AR CT FL) และระดับชั้น ม.1–ม.6 ของโรงเรียนผ่านหน้า “ข้อมูลหลัก” ก่อน
(ฝ่ายวิชาการเป็นผู้ยืนยันชื่อ/รหัส) — ระบบนำเข้าสร้างกลุ่มสาระเองไม่ได้โดยออกแบบ

## 3. ลำดับที่ถูกต้อง

1. ยืนยัน/สร้างกลุ่มสาระและระดับชั้นของโรงเรียน (คน)
2. ชุดแผนการเรียน (9) → ตรวจ → หัวหน้าอนุมัติ (≠ ผู้สร้าง) → บันทึก
3. ชุดรายวิชา (404) → ตรวจ → อนุมัติ → บันทึก
4. กด “ตรวจซ้ำทั้งชุด” ที่ชุดการจัดรายวิชา/กิจกรรม/ผลการเรียนรู้ → dependency error หายเอง (เป็น needs_review เท่านั้น)
5. ตรวจ/อนุมัติ/บันทึกชุดที่เหลือ

## 4. Parser — ข้อเสนอ (ไม่เปลี่ยนค่าต้นฉบับ)

- ไม่พบข้อผิดพลาดของ parser ที่ทำให้เกิด error 2,401 แถว (เป็นลำดับการนำเข้า) · `raw` และ `normalized` ไม่ถูกแก้
- WRAPPED_TEXT (57+13): ชื่อวิชาในตารางโครงสร้างถูกตัดบรรทัดต่างจากคำอธิบายรายวิชา → เสนอให้ parser เก็บทั้งสองค่าไว้เทียบกัน
  (ทำอยู่แล้ว) และให้คนเลือกค่าเมื่อตรวจ; ห้าม parser เลือกค่าเอง
- NO_DESCRIPTION (66): ต้นฉบับไม่มีคำอธิบายรายวิชา → ปล่อยว่าง ให้คนยืนยัน
- IS (`IS_NO_AREA`, `IS_STAGE_SPLIT`): แยก IS ตามช่วงชั้นแล้ว; กลุ่มสาระของ IS ต้องให้ฝ่ายวิชาการตัดสิน
- “ชุมนุม”/“IS3” ในกิจกรรมไม่มีชั่วโมงในต้นฉบับ (V40) → ไม่เติมเอง
